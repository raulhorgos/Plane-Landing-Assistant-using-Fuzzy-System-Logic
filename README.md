# Plane Landing Assistant using Fuzzy System Logic 

Developed a pilot assistance system using Fuzzy Logic to calculate a landing "Risk Factor"
(0–100%) based on real-time flight conditions, using an MPU6050 sensor, Arduino, and an
LCD display. The system processes four critical flight parameters: altitude and the angle of
the plane relative to the ground. The data from the gyroscope and accelerometer was
processed by the code in Arduino IDE and the LCD displays the information for angle
adjustment.
